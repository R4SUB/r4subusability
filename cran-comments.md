## Submission notes

This is the first submission of r4subusability. It is part of the R4SUB
(Ready for Submission) ecosystem and fills the usability pillar: all regulatory
authority profiles in 'r4subprofile' allocate weight to usability evidence, but
no existing package emits it. This package quantifies variable label quality,
Define-XML completeness, dataset annotation coverage, and reviewer guide
presence, emitting standardized R4SUB evidence via 'r4subcore'.

The imported package 'r4subcore' is available on CRAN, as are the suggested
'r4subdata'; 'cli', 'tibble', and 'utils' are base or CRAN packages.
